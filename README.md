# Rutz's PF2e Forge

[Discord](https://discord.gg/bB7Ca666Bv) · [Wiki](https://github.com/Rutz179/rutz-pf2e-forge/wiki)

Make gear durability visible and part of play.

- **Durability** — weapons and armor get GM Core material Hardness, HP and BT; HP bars and broken tags on sheets; a chat notice when gear loses HP.
- **Broken & destroyed** — broken armor gets its AC penalty as an effect, broken weapons an attack penalty (or rules as written), destroyed weapons can't attack.
- **Repair** — players roll their own Repair check; results applied by the rules. Ask a party member to repair with a chat card.
- **Staff Maker** — the GM builds staves whose spells PF2e Dailies reads.

## Install
Foundry → *Add-on Modules* → *Install Module* → Manifest URL:
```
https://github.com/Rutz179/rutz-pf2e-forge/releases/latest/download/module.json
```
Foundry VTT v13–v14 · PF2e · English / 한국어

The *Durability* button on the sheet header, or `game.rutzForge.durability(actor)`.
